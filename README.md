# Magxxic Direct-to-MX Email Sender

This repository contains the Magxxic Direct-to-MX Email Sender, available in both Python and Node.js implementations.

## Project Structure

- **`python_sender/`**: The Python implementation of the tool.
- **`node_sender/`**: The Node.js implementation of the tool.
- **`index.html`**: A sample IONOS webmail phishing template (for educational/research purposes).
